☁️ Cloud Sync

Set a sync code below, then enter the same code on your other devices. Any device using the same code shares the same cloud copy of your data. Treat the code like a password — anyone who has it can read and change your data.

Manual sync
Sync now compares timestamps and keeps whichever copy is newer. The overwrite buttons force a direction — use them if something looks out of sync.
💾 Data storage
