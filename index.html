✏️ Editing record
Portfolio determines which holding this purchase feeds — buy the same stock under two different portfolios (e.g. MTNN for both Long-Term and Short-Term) by recording each batch of units with its own Portfolio selection. Type: Sell records reduce shares held (and are used to compute realised gains) instead of adding to the position. IPO/Rights Application records the cash applied for a subscription that hasn't been allotted yet — it's tracked as pending in the ledger below but doesn't affect shares held, DCA, or dividend-qualifying shares until you confirm its allotment. "Funding/Settlement Account" picks which cash account (Chart of Accounts → Cash & Bank Accounts) the cash side of this transaction posts to in the accounting ledger.

🩺 Data Health
Checks your records for anything that stops the ledger, statements or charts from being accurate. Fix tools only change the field named on the button and are saved like a normal edit — export a backup first if you're making a large change.
💾 Data storage

When a sync code is set below and you're online, every change is saved straight to the cloud automatically. Your browser's localStorage is just a temporary local cache — it holds your data while offline (or before a sync code is set) and syncs to the cloud the moment you're back online. Export a backup any time as an extra copy; if cloud sync is on, exporting also saves a timestamped backup to the cloud.

☁️ Cloud Sync

Set a sync code below, then enter the same code on your other devices. Any device using the same code shares the same cloud copy of your data. Once set, saving anything in the app pushes it straight to the cloud automatically while you're online — no manual sync needed. If you go offline, changes are held locally and pushed as soon as your connection returns. Treat the code like a password — anyone who has it can read and change your data.

Manual sync
Sync now pushes this device's changes if it has any not yet uploaded (e.g. made offline); otherwise it pulls the cloud copy, which is treated as the master. The overwrite buttons force a direction — use them if something looks out of sync.

Add manual / adjusting entry
✏️ Editing
Manual entries must balance (total debits = total credits) before they can be posted. Amounts are entered in each account's own currency; when an entry involves foreign-currency accounts, an exchange-rate field appears for each foreign currency (defaults to the current rate — change it to the actual rate if different) and balance is checked in ₦ equivalent. Auto-generated entries (from purchases, dividends, cash flow, and mutual fund transactions) can't be edited here directly — edit the source record instead and the ledger will regenerate.
📥 Import journal entries from Excel
One row per journal line. Columns: Date, Account, Debit, Credit are required; Entry (a reference that groups lines into one entry) and Memo are optional. Amounts are in each account's own currency; an optional Rate column (₦ per 1 unit of a foreign-currency account) overrides the current rate, and each entry must balance in ₦ equivalent. Without an Entry column, lines sharing the same Date + Memo are grouped. Account can be a code (e.g. 1010) or an account name. Each entry must balance (debits = credits) and can only post to leaf accounts, not parent accounts. Imported entries are saved as manual entries; nothing is saved until you review the preview and click Import.

Add account
✏️ Editing
Built-in accounts can't be removed and keep their original type and normal balance, but their code, name, note and parent can all be edited — the app tracks each built-in account internally, so renaming its code (or moving it under a parent) doesn't disconnect its postings. You can add sub-accounts under any top-level account (e.g. 1011 Ecobank, 1012 Atlass Wallet under Cash & Bank Accounts) — a sub-account always takes its type and normal balance from its parent. A parent account (one with sub-accounts) can't be selected in journal entries — only leaf accounts can — and its balance shown below is simply the total of its sub-accounts. Sub-accounts are one level deep. Click any row to edit it. Each account has a currency (default ₦, the base currency) — its postings are stored in that currency and translated to ₦ in reports; the currency is locked once the account has postings.
